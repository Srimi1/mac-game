# Security Policy

## Supported version

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue. Use GitHub's **Security** tab and choose **Report a vulnerability** to send a private report to the repository owner.

Include the affected version, macOS version, reproduction steps, and the likely impact. You should receive an acknowledgement within seven days.

The game is offline and stores only local settings and campaign progress. It does not contain accounts, analytics, advertising SDKs, or a network client.
